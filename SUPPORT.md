# Support / 支持

## English

Before requesting support:

1. Confirm Java 21 and Paper/Folia 1.21.11.
2. Reproduce with the latest ICUAC release and official preset.
3. Remove secrets, IP addresses, tokens, and private player data from logs.
4. Include ICUAC version, server build, Java version, relevant configuration, steps, expected result, actual result, and complete error stack trace.

Use [GitHub Issues](https://github.com/Lazyzouo/ICUAC/issues) for reproducible bugs and [GitHub Discussions](https://github.com/Lazyzouo/ICUAC/discussions) for configuration questions. Do not report security vulnerabilities publicly; follow [SECURITY.md](SECURITY.md).

Only Paper/Folia 1.21.11 with Java 21 is the official tested baseline.

## 中文

请求支持前请：

1. 确认 Java 21 与 Paper/Folia 1.21.11。
2. 使用最新 ICUAC 与官方预设复现。
3. 从日志移除密钥、IP、Token 和私人玩家数据。
4. 提供插件版本、服务端构建、Java 版本、相关配置、复现步骤、预期/实际结果及完整报错。

可复现错误请使用 [GitHub Issues](https://github.com/Lazyzouo/ICUAC/issues)，配置问题请使用 [GitHub Discussions](https://github.com/Lazyzouo/ICUAC/discussions)。安全漏洞不要公开提交，请遵循 [SECURITY.md](SECURITY.md)。
